# theo-chem-skills

Pi skills for theoretical chemistry and electronic structure development.

## Layout

Each skill lives in its own directory with a `SKILL.md`:

```
skills/
  <skill-name>/
    SKILL.md          # frontmatter (name, description) + instructions
    ...               # optional scripts, templates, references
```

## Installing

Clone this repo to `~/.pi/agent/git/github.com/RuiyiQM/theo-chem-skills` — pi discovers skills automatically from that path.
